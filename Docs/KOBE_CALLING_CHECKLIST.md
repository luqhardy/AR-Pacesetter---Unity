## A. 実機リハーサル(iPhone + XREAL One)

**準備**
- [ ] `master` の最新を Mac で pull → Unity のエクスポートを用意する: Mac の Unity で Build → Export iOS
      (アクティブなプラットフォームは **iOS**)、または公開済みのものを `tools/fetch-unity-export.sh` で取得
- [ ] Xcode: Product → Clean Build Folder → 実機へ Run(`relink-unity-export.sh`・`ProjectSettings` の戻しは不要)
- [ ] グラスの画面モードが **Follow(固定)**

**グラスの表示**
- [ ] ホーム → メニュー → 体験モード(展示)。上部のチップが **「グラス接続中」**(「ミラーリング中」ではない)
- [ ] グラスにボタン・カメラ映像が出ず、アバターと HUD だけが現実に重なる
- [ ] iPhone の画面は操作パネル(グラスと同じ絵ではない)
- [ ] グラスを抜き差しすると、チップが「未接続」→「グラス接続中」に変わる

**立ったまま(約55秒)** — iPhone は胸のマウントに入れ、ブースの開けた方向を向く
- [ ] 開始 → 猶予の秒数が数えられる → グラスで 3・2・1・START
- [ ] 3m先のアバターが**頭から足元まで**見える(145cm)
- [ ] 遅れ(10〜22秒): アバターが約9m先へ離れて**赤**、足元から光のライン、右上のペースが赤。頭が視野の上へ切れない
- [ ] 追い抜き(28〜35秒): アバターが近づいて青寄り、ペースは緑
- [ ] 最後の直線(40秒〜): ゴールラインが見えてくる → ゴールで自動終了 →「完走しました」
- [ ] 体の向きを90°変える → アバターが**約0.5秒で正面へ戻る**(グラスの視点も一緒に回る)
- [ ] 呼吸・軽い揺れではアバターが左右に揺れない
- [ ] 体験中に**一度もアバターが消えない**(フェードアウト・赤字の GPS 警告が出ない)
- [ ] 途中で「中断」→ 待機画面へ戻る → 「次の方を開始」ですぐ次が始まる

**数歩あるく(60秒)** — 周囲2〜3mに人や物が無いこと
- [ ] 歩くとアバターが3m前を追従する。向きを変えると正面へ回り込む
- [ ] 止まってもアバターは消えない。60秒で自動終了

**何も残らないこと**(来場者の体験は記録ではない)
- [ ] 履歴(ホーム → 履歴)に体験の走行が増えていない
- [ ] ヘルスケアアプリにワークアウトが増えていない
- [ ] 開発者モードの走行ログCSV一覧に体験の分が増えていない

**体験モードの後、通常の走行**(Info.plist のシーン定義を変えたため一度は確認)
- [ ] 通常の走行フローで起動し、グラスに AR が出る
- [ ] 準備画面の ARグラス行が実際の状態を出す: 挿していれば「接続済み」、挿していなければ「手動で接続」ボタン(押すと「手動(未検出)」)

## B0. いちばん手軽な予備: Mac + グラス + ブラウザ(Unity・iPhone 不要)

[tools/booth-fallback/glasses-fallback.html](../tools/booth-fallback/glasses-fallback.html) を開くだけ。ネットに繋がなくても動く。
立ったままの台本(52秒)を**録画のように再生する**だけで、来場者の動きも向きも追わない — 正面を向いて立ってもらう。
- [ ] Mac の USB-C にグラスを挿し、システム設定 → ディスプレイで**拡張**にする(ミラーリングではなく)
- [ ] ファイルを Chrome か Safari で開き、ウインドウをグラス側の画面へ移して **F**(全画面)。黒はグラスでは透明
- [ ] **Space** で開始: 猶予10秒(アバターが立って待つ)→ 3-2-1-START → 52秒 → 挨拶して粒になって消える → 結果カード
- [ ] 次の方は **Space** でやり直し。途中で止めるのは **S**、**H** で操作の一覧(グラスではほとんど見えない暗さ)
- [ ] 猶予は **D** で 0/5/10/15/20秒、**L** で終わるたびに5秒後から自動で繰り返す(URL に `?delay=5&loop=1` でも可)
- [ ] 一度通して、グラスでアバターの大きさ・HUD の位置が実機の体験と大きく違わないこと(画角が違う機種は `?vfov=` で合わせる)
- [ ] **動画でも持っておく**(ブラウザも使えないとき): `node tools/booth-fallback/render-video.mjs` で同じ内容を
      1920x1080・60fps の MP4 に書き出せる(要: Node 22+・Chrome か Edge・ffmpeg。約6分)。黒は透明なので、
      グラスを拡張ディスプレイにして QuickTime 等で全画面再生する。1本 約78秒(猶予10秒 → 3-2-1-START → 52秒 → 結果)

## B. 予備手段: Windows ノート + グラス(立ったままのみ)

Mac / iPhone 側で問題が出たときの代替。**一度通しておかないと当日使えない**(Unity でプロジェクトを開くのに時間がかかる)。
- [ ] ノートの USB-C が DisplayPort Alt Mode に対応している(グラスに画面が出る)
- [ ] Unity 6000.3.17f1 でプロジェクトを開いたことがある(初回は `Library/` 生成で長い)
- [ ] `SampleScene` を開き Tools → AR Pacesetter → Booth Demo → **Start Standing**
- [ ] Game ビューをグラス側の画面へ出して最大化 — 黒が透け、アバターと HUD だけが見える
- [ ] 台本が最後まで進み、Tools → Booth Demo → Stop で止まる
- 注意: 来場者の動きは追えない(ARKit が無い)。向きを変えてもアバターは追ってこない — 正面を向いて立ってもらう

## C. 電源と発熱(本番の運用時間で通す)

iPhone がグラスへ給電し、ARKit と外部ディスプレイを胸のマウントの中で動かし続ける。
- [ ] **パススルー給電の USB-C ハブ**経由で、グラスを挿したまま iPhone が充電される
- [ ] 立ったまま体験を**60分**連続で回す(§10 の連続稼働)。開始 ___% → 終了 ___%
- [ ] 60分後もフレームが落ちていない(開発者モード `render.maxFrameMs` ___ms)・画面が暗くならない・発熱警告が出ない
- [ ] 予備の iPhone(同じビルド)を用意し、交代の手順を一度試す

## 問題が起きたら

| 症状 | 対処 |
|---|---|
| チップが「ミラーリング中」/ グラスに iPhone の画面が映る | グラスを抜いて挿し直す。直らなければアプリを再起動。それでもだめなら B0 / B の予備手段 |
| チップが「グラス未接続」 | ケーブル・ハブの接続、グラスの電源。ハブ無しで直挿しを試す |
| アバターが見えない | 開けた方向を向いているか(壁の向こうに立っている)。iPhone の画面に紫の「アバター非表示: …」が出ていれば、その理由を記録 |
| アバターが左右にふらつく | チェストマウントの固定を確認(iPhone の向きがそのままアバターの向き) |
| 開始できない(「開始できませんでした: …」) | 理由を記録。通常の走行が進行中なら終了してから |
| iPhone が熱い・電池が減る | 予備 iPhone と交代(C) |
