iPhone へのビルド手順(Mac)

Mac に iPhone を USB で挿して、コマンド1つで最新のアプリを入れる手順です。 ソースの更新・Unity エクスポートの取得・署名・ビルド・インストール・起動までをスクリプトがまとめて行います。 無料の Apple ID で使えます。

初回の準備 15〜30分 2回目から コマンド1つ 7日ごとに入れ直す

用意するもの

  • Mac と Xcode 26(App Store から。約15GBなので先に入れておく)
  • iPhone(iOS 26・iPhone 12 Pro 以上)と USB ケーブル
  • Apple ID(無料のものでよい)
  • GitHub アカウント

1初回だけの準備 1回だけ

Xcode に Apple ID を追加する

  1. Xcode を一度起動し、追加コンポーネントのインストールを済ませる
  2. Xcode → Settings → Accounts の + から自分の Apple ID でサインイン
  3. 表示されたチーム(Personal Team)を選び、Manage Certificates… → + → Apple Development

GitHub の CLI を入れてログインする

Homebrew が無ければ先に brew.sh の1行を実行してください。

brew install gh
gh auth login

質問には GitHub.com → HTTPS → Login with a web browser と答え、ブラウザでログインします。

リポジトリを取得する

すでに手元にある人は不要です(下の手順2で自動的に最新になります)。

git clone --depth 1 https://github.com/luqhardy/AR-Pacesetter---Unity.git

iPhone を開発に使えるようにする

  1. USB で Mac に挿し、iPhone に出る 「このコンピュータを信頼」 で信頼する
  2. iPhone の 設定 → プライバシーとセキュリティ → デベロッパモード を ON(再起動を求められる)

デベロッパモードの項目が無いときは、Xcode を開いた状態で iPhone を挿し直すと現れます。

2ビルドして iPhone に入れる 毎回

iPhone を USB で挿し、ロックを解除した状態で、ターミナルで次を実行します。

cd AR-Pacesetter---Unity
tools/build-to-iphone.sh
  • 初回は10分ほどかかります。2回目からは数分です。
  • 途中で Mac のパスワード(キーチェーン)を聞かれたら、入力して 「常に許可」 を押します。
  • チームID・Bundle ID・iPhone は自動で見つけ、次回のために覚えます。2回目からは引数は要りません。
  • 最後に 完了: … を ○○ の iPhone に入れました。 と出れば成功です。

3iPhone で開発元を信頼する 初回だけ

無料の Apple ID で入れたアプリは、初回だけ iPhone 側で信頼が必要です。 スクリプトが「起動できませんでした」と出したときがこれにあたります。

  1. 設定 → 一般 → VPNとデバイス管理
  2. 自分の Apple ID を選んで 信頼
  3. ホーム画面のアプリを開く

47日たったら

無料の Apple ID で入れたアプリは7日で起動しなくなります(Apple の仕様)。 そのときは手順2の tools/build-to-iphone.sh をもう一度実行してください。 アプリ内の走行ログ(CSV)は消えません。

必要なときだけ使うオプション

オプション使う場面
--no-pull最新にせず、今の手元のソースのまま入れる
--release実地テストで M2P などを計測するとき(既定は Debug)
--device "名前"iPhone を複数つないでいるとき。名前か UDID を指定
--team ABCDE12345Apple ID のチームが複数あるとき(表示された10文字のどれか)
--bundle-id com.○○.pacesetter以前に手作業(prepare-free-signing.sh)で入れていて、その走行ログを引き継ぎたいとき。以前と同じ値を指定する
 
tools/build-to-iphone.sh --release

うまくいかないとき

表示対処
Apple ID のチームが見つかりません手順1の「Xcode に Apple ID を追加する」をやり直す(証明書の作成まで)
iPhone が見つかりませんケーブルを挿し直し、「このコンピュータを信頼」とデベロッパモードを確認する
チームが複数あります / iPhone を選んでください一覧に出た値を --team / --device に付けて再実行する
gh にログインしていませんgh auth login を実行する
git pull できませんgit status で手元の変更を確認する。今のまま入れるなら --no-pull
このエクスポートの後に Unity 側で…が変わっていますエラーではなく注意です。Unity 側の最新の変更はまだ入っていないので、ルクマンに新しいエクスポートの公開を頼む
ビルドに失敗しましたios/build/xcodebuild.log をルクマンに送る
インストールに失敗しましたiPhone のロックを解除して再実行する
起動できませんでした手順3(開発元を信頼)
署名の設定はコミットしない

スクリプトはビルドの間だけ署名の設定(HealthKit・チーム・Bundle ID)を書き換え、終わったら自動で元に戻します。 もし git status に ios/AR_Runner_UI の変更が残っていたら、コミットせずに git checkout -- ios/AR_Runner_UI で戻してください。

Mac が無い人は

TestFlight での配布を準備中です。チームで有料の Apple Developer Program を用意すると、 iPhone の TestFlight アプリから入れられるようになります(Mac も7日ごとの入れ直しも不要)。

詳しい仕組みは リポジトリ の Docs/BUILD_ON_BORROWED_MAC.md と Docs/TESTFLIGHT.md。 このページの元は site/index.html(master へ入ると自動で公開)。
